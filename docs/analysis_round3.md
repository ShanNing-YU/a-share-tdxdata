### 1. 连接被拒根因（反复踩坑终于定位）
- 早上（11:15 前）重放完整握手序列 → 服务器**静默忽略 0c01 + 断开**；0c02/0c04-0c0a 单独发全部 0B（只有 0c03 tdxlevel 有 195B 响应）
- 午休后（11:45+）同连接同请求 → **0c02/0c03/单只快照全通**！
- 用户配合确认「抓包完就关了客户端」→ 关客户端不是关键；**最可能是连续多次连接被服务器临时限流**（休息冷却后恢复）
- 结论：**0c01 加密请求 = 登录身份校验，内容固定但绑定合法客户端（无法重放）**；0c02/0c03 和数据命令是普通协议不需要 0c01（之前以为必须 0c01 是错的）

### 2. 协议格式定稿（已验证）
```

       -> 响应 195B (回显 cmd+seq + b300b300)

  market: 00=深市 01=沪市（00 01 02 字节在 d10f 后）
  响应 182B: 帧头(16) + market(1) + code6 + 32 个 float 分时价格（最新价=最后 float）
响应帧头: b1cb7400 + 回显cmd + seq + ...
```
