# tdxdata 协议文档（2026-09 通达信新版行情协议）

逆向来源：2026-09-14/15 三份 pktmon 抓包（收市 + 盘中）+ 逐字节复线验证。
老 pytdx 协议 2026-09-10 起被服务器拒绝（版本标识 + 命令族改动），本协议为新版适配。

## 概览

| 项 | 值 |
|---|---|
| 传输 | TCP 7709（标准行情服务器，43 个国内主站） |
| 连接序列 | `0c02`(init 13B) → `0c03`(tdxlevel 认证 42B) → 数据请求 |
| 版本标识 | `18 7b 00 01`（新客户端；老库 `08 64 01 01` 被拒） |
| 响应帧头 | 16B 起始（`b1cb7400` + 回显 cmd(2B) + seq(2B) + 长度/状态字段）；帧头长度因命令而异(16/18/20B，quotes 实测 18B，代码用试探定位） |
| 数据压缩 | zlib 流式（可跨 TCP 段，decompressobj 自动切流） |
| 分时/快照 | 单只请求 → 182B = 32 个 float 价格点（当日分时，最新价=末元素） |

## 认证与初始化

```
0c02 = 0c0218940001030003000d0001                      # 13B init/订阅
0c03 = 0c031899000120002000db0f7464786c6576656c
       000000295cf740110000000000000000000000000005   # 42B tdxlevel
       ("tdxlevel" ASCII + 版本 float 7.9x)
0c03 响应 = 195B（回显 cmd+seq + b300b300 + 全零）
```

## 单只快照（SNAP）— 已投入生产

```
请求 49B:
  0c09 0041 0300 2700 2700 d10f [market 1B] [code 6B ASCII]
  0000000000000000000000000000000001001400000000010000000000
  market: 0x00 = 深市, 0x01 = 沪市
  同 code 不同 market = 完全不同标的（000001: m0 平安银行, m1 上证指数）

响应 182B:
  b1cb7400 0c09 0041 0300 d10f [count 2B=0x00a6=166] [count 2B]
  0000 [market+code 7B] 00×18
  01 00 [u16] 00 00 00 00 00 00 3c 00
  [32 × float32 分时价格，最新价 = 最后一个]
  无效代码 → 58B（count=0x002a=42 且无价格数据）
```

实测速度：每连接每请求固定 ~3s 延迟；43 连接并发 ≈ 5.7-6.8 只/s。
**不要**把单连接频率压到 3s 以下、**不要**单出口开 >60 并发——会触发出口级限流（热状态，需长冷却）。

## 批量快照（❌ 已放弃）

```
深市: 000000000000 c002 c002 1000 6400 00 [code6 × N]
沪市: 000000000000 7c05 7c05 0f00 c800 01 [01 code6 × N]
北交所:000000000000 ..  0f00 a500 02 [02 code6 × N]
0c01版: 0c01 2c88 0000 c900 c900 4c05 0500 000000000000 [1b 00] + codes
```
依赖 `0c01`（e538... 固定内容，绑定合法客户端身份，无法重放）→ **按用户红线已放弃**，最终方案 = 单只 bars 循环 + 43 主站并发（见 batch_daily_reverse_guide.md）。

## 限制与已知坑

| 项 | 状态 |
|---|---|
| 全量历史 K 线（800 根） | ❌ 客户端不拉（本地文件+增量），服务器无此接口 |
| 批量快照 | ⚠️ 需 0c01 会话（身份绑定），单只 SNAP 不受影响 |
| 单只 SNAP 深沪深指数 | ✅ 全可用 |
| 0c01 加密登录 | ❌ 无法重放（身份校验，需逆向生成算法） |
| 坏 IP | `123.60.102.110` `124.71.137.253` `124.71.191.151` 连接即 reset，已剔除 |
