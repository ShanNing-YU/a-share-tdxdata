## C. 协议不可能提供 ❌（增值数据，需 HTTP 源）

- 资金流（主力/散户/北向分项）
- 龙虎榜、两融余额、北向持股
- 涨跌停池（涨停/跌停/强势列表）
- 五档盘口详细买卖队列（7709 无此字段，可能在其他端口/level2）
- 财务数据、股本结构、F10

## C2. F10/财务指标 = HTTP 网页，不在行情协议（2026-09-15 新抓包证实）

- 用户抓 tdx_dl.pcapng 点 F10 → 抓包里发现 `Host: data.tdx.com` + `GET /web-res/f10-static/v1/lib/echarts.f10.js`（jquery/req_sf.js）
- **F10 是通达信官方 HTTP 网页服务**（data.tdx.com:80），用 echarts 渲染，与 7709 行情协议完全两条通道
- 复权操作（000059 日线 不复权→前复权→回不复权）在请求层**无差异**（K 线请求只发一次，复权=客户端本地用除权因子重算）
- 000059（华锦股份 5.43 元）分时数据 = SNAP 形式（`01 00 91 09 00×6 3c 00 + 60 floats`）
- 0b00 44B = 客户端注册/心跳（带本机 IP+时间戳），与行情无关

## C3. ❗推翻：财务/盘口指标旧命令在新服务器原样可用（16:00 实测，用户要求借助旧协议）

**GetFinanceInfo(0c1f) + GetSecurityQuotes(老格式) 在 2026 新服务器全部可用！**
pytdx 库直接调用失败只是因为 **setup 序列不兼容**（老 SetupCmd1-3 vs 新 0c02/0c03），手工 `0c02 → 0c03 → 旧命令` = 全通。

- `GetFinanceInfo`：`0c1f 1876 0001 0b00 0b00 1000 0100 + market + code6`（21B）
  → 流通股本 15.99 亿股 / 总股本 / 省份行业 / 更新日期 20260903 / IPO 日期 / 总资产 / 净资产 / 主营收入 / **净利润** / 每股净资产 / 股东人数（28 字段）
- `GetSecurityQuotes`：老格式 `0x010c + 0x02006320 + ... + <B6s>×N`（老 pytdx pkg_header 原样）
  → **现价 5.41 / 昨收 5.44 / 今开 5.42 / 最高 5.48 / 最低 5.28 / 成交量 / 成交额 / 五档**（000059 实测全对）
- 用户要的指标全部可算：换手 = vol/流通股本；PE = 价/(净利润/总股本)；振幅 = (高-低)/昨收；流通市值 = 流通股本×价
- 已入库：`tdxdata/commands/finance.py`（✅ 实测）+ `tdxdata/commands/quotes.py`（✅ 单只实测）
- ⚠️ 待办：quotes 多只响应解析有小偏移（每只循环 pos 未对齐多只模式），先单只循环用
