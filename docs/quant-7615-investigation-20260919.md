# 量化模拟客户端 7615 端口调查（2026-09-19）

> 背景：SPEEDUP_PLAN P0——验证「通达信量化模拟客户端」是否连专用行情端点（可绕过 7709 的 4s/请求限速）。
> 结论先行：**7615 不是行情端点，量化版行情仍走 7709 标准端口，不能提速。P0 终止。**

## 证据

### 1. netstat（量化客户端 TdxW.exe PID 10264 活跃连接）
```
116.205.141.100:7615  ESTABLISHED   ← 从未见过的 IP+端口（本次调查对象）
175.178.128.227:7709  ESTABLISHED   ← 已知标准主站（腾讯云段）
```

### 2. 新抓包 quant_cap.pcapng（2026-09-19，用户操作 K线/分时/复权/换股）
- **7615 流量 = 0**（连接已建立但抓包期间无任何包）
- 7709 流量 = 106KB：所有含股票代码的行情请求（0c5e/0c61/0c7a~0c98 命令族，000001/000002/000006/000017/399001 等）全在 7709
- → 用户行情操作 100% 走 7709，7615 与行情无关

### 3. 旧抓包 7615 流量（tdx3 / tdx_dl，2026-09-15）
7615 上三类内容，全部非行情：
| 内容 | 说明 |
|---|---|
| `0b00/0b03/0b09` 44B→39B | 心跳/时间同步（约 30s 一轮，多服务器） |
| `0b04` 74B：`TDXW...autoup8` | 客户端版本上报 / 自动更新检查 |
| `K06...ACL.checkuser` → `{"Length":"652","AttachLog":""}` | 账号/用户校验 |

另：49.232.135.168:7615 上有 HTTP（`GET /site/tdxf10/...`，Host: static.tdx.com）= F10 静态资源 CDN。

### 4. 涉及服务器
47.106.34.194 / 116.205.141.100 / 121.37.16.86 / 121.37.11.198 / 49.232.135.168（HTTP）——均为「服务/下载中心」节点，普通客户端同样连接（tdx3/tdx_dl 旧抓包均有）。

## 结论
- **7615 = 通达信服务/下载中心端口**（心跳 + 版本更新 + ACL 用户校验 + F10 CDN），不是行情端点
- 量化模拟客户端没有专用行情端点，行情 K 线/分时/复权全走 7709 标准端口
- 7709 的 ~4s/请求限速是服务器端策略 → 量化版同样受限
- **P0 终止**：量化版不能提速。P2（tqcenter 接入）前提不成立，P3 维持留档
